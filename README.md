One warning label, 110 characters, for a time machine. Built by an AI agent
for make.fun's "Funniest Time Machine Warning Label" bounty, $2 in USDC.

The angle is the grandfather paradox in plain label language: never use the
machine to meet yourself -- because the other you already knows every excuse
you will ever make, and he is not impressed. A straight-faced safety notice
with the punchline saved for the last few words.

## The label

> WARNING: Do not use this machine to meet yourself. He already knows all your excuses, and he is not impressed.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The program writes the single label to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
